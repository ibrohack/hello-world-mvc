Hello World MVC is a JavaFX application in which users sign in and see their data. It shows how a professional application is organised in layers, documented and packaged.

Architecture

The application follows a two-layer architecture. The user interface layer is made of the FXML views and their controllers, and the data access layer (DAO) reads the users from a data store. The model is shared by both layers.

Selecting the data store

On each run, {@link tartanga.dami2.din.helloworldmvc/tartanga.dami2.din.helloworldmvc.dao.DaoFactory} reads the {@code config.properties} file through {@link tartanga.dami2.din.helloworldmvc/tartanga.dami2.din.helloworldmvc.dao.DaoConfig} and creates the implementation selected with the {@code dao.implementation} key: {@code DATABASE} or {@code FILE}. The file is not tracked by Git because it contains the database credentials: each developer copies {@code config.properties.example} and sets their own values.

Error handling and logging

The data access layer reports problems with checked exceptions ({@link tartanga.dami2.din.helloworldmvc/tartanga.dami2.din.helloworldmvc.exception.DaoException}, {@link tartanga.dami2.din.helloworldmvc/tartanga.dami2.din.helloworldmvc.exception.InvalidCredentialsException} and {@link tartanga.dami2.din.helloworldmvc/tartanga.dami2.din.helloworldmvc.exception.ConfigurationException}), which the controllers turn into messages for the user. The values typed by the user are validated before they reach the data access layer, and every class records its activity with {@code java.util.logging}.
